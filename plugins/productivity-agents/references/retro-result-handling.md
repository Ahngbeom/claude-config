# 회고 에이전트 결과 처리

`jira-retrospective`·`commit-retrospective`가 돌려준 결과를 메인 대화에서 처리하는 순서다. 에이전트는 사용자에게 물을 수 없어서, 판단이 필요한 일을 결과에 담아 돌려준다.

1. **빠진 입력이나 후보 목록**: 결과가 빠진 입력 목록이거나 담당자·작성자 후보 목록이면, AskUserQuestion으로 그 값만 묻고 받은 값을 더해 같은 에이전트에 다시 위임한다.
2. **민감정보 검출** (결과가 "사용자 확인 필요"로 시작): 검출 항목을 줄 번호·내용·권장 조치와 함께 그대로 보여 주고 묻는다.
   - 자동 수정: 권장 조치대로 파일을 고친 뒤 `productivity-agents:retrospective-validator`를 다시 불러 검출이 0건인지 확인한다. 남은 항목이 있으면 보여 주고 다시 묻는다.
   - 그대로 유지: 파일을 두고, 민감정보가 남아 있다고 알린다.
   - 삭제: 저장된 파일을 지우고 끝낸다.
3. **같은 기간 기존 파일**: 결과에 기존 파일명이 함께 있으면 새 회고록은 `-vN` 이름으로 따로 저장돼 있다. 두 파일을 알리고 묻는다.
   - 둘 다 유지
   - 교체: 기존 파일을 `<이름>.backup`으로 옮기고 새 파일을 기존 이름으로 바꾼다.
   - 새 파일 삭제
4. **보고**: 최종 파일 경로와 통계 요약을 알린다. 회고록 본문을 대화에 다시 붙이지 않는다.

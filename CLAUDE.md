# claude-config

Claude Code plugin marketplace (`ahngbeom-claude-config`) plus the tracked copy of the global `~/.claude` files. The agent catalog, routing keywords, slash commands, and install steps live in `README.md`. This file covers working on the repo itself.

## Language Preference

Respond in Korean (한국어) unless explicitly requested otherwise.

## Layout

| Path | Role |
|------|------|
| `.claude-plugin/marketplace.json` | Marketplace manifest. Every `plugins/<name>` is listed here with a `name` matching its `plugin.json` |
| `plugins/<name>/` | One plugin per domain: `.claude-plugin/plugin.json`, `agents/*.md`, `commands/*.md` |
| `global/` | Tracked `~/.claude` files: `CLAUDE.md`, `hooks/guard-k8s.py`, `cleanup.sh`. Synced with `scripts/sync-global.sh` |
| `shared/references/` | Canonical shared assets. Copies under `plugins/` and `codex/` are generated by `scripts/sync-shared.sh`; edit the canonical file only |
| `codex/skills/` | OpenAI Codex skill sources, intentionally not registered in the marketplace |
| `docs/` | Guides, `settings.example.json`, and design specs under `docs/superpowers/` |

## Conventions

- Agent file: `name` equals the filename; `description` is a YAML block scalar carrying the `<example>` triggers; `model` is haiku, sonnet, or opus; `color` is red, blue, green, yellow, purple, orange, pink, or cyan. No `tools` restriction.
- Command file: `description` is required, `argument-hint` and `allowed-tools` are optional. No `name` or `context` field; the filename is the command name.
- Skill vs command: user-invoked `/name` goes in `commands/`, model-invoked goes in `skills/<name>/SKILL.md`. This repo currently ships commands only.
- Plugin metadata: `version` is semver and `license` matches the root `LICENSE`.
- Global instruction edits: change either `~/.claude/CLAUDE.md` or `global/CLAUDE.md`, then run `scripts/sync-global.sh pull` or `push` so both match before committing.

## Verification

- `scripts/validate.sh` runs the same checks as CI: JSON validity, plugin/marketplace consistency, frontmatter rules, shared-asset drift, script syntax.
- `scripts/sync-global.sh check` reports drift between `global/` and `~/.claude`. Local only; CI has no `~/.claude`.
- `scripts/sync-shared.sh --check` after editing anything under `shared/`.

## Using the Plugins From This Machine

The agents and slash commands in `README.md` exist only where the plugin is installed and enabled. Check `~/.claude/plugins/installed_plugins.json` and `enabledPlugins` in `~/.claude/settings.json` before routing work to one. When it is not available, do the task directly and say so.

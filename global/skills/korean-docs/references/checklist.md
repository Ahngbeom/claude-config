# 게시 전 검수

모든 항목에 예/아니오로 답한다. '아니오'가 하나라도 있으면 고친 뒤 제출한다.

## 독자 (D)

- D1. 이 채널의 독자가 추가 질문 없이 다음 행동을 정할 수 있는가

## 구조 (L)

- L1. 첫 3줄 안에 결과, 결정, 요청 중 하나가 있는가
- L2. 템플릿의 섹션 순서를 지켰는가(사용자 지정 구성이 있으면 그것을 지켰는가)
- L3. 표·목록·문단을 `layout.md` 형식 선택 기준대로 골랐는가
- L4. 길이 상한을 넘는 항목, 문단, 코멘트가 없는가
- L5. 내용이 없는 섹션이나 "해당 없음"만 적힌 섹션이 없는가(리스크·배포 순서 제외)

## 문체 (S)

- S1. 서술 어미가 한 종류로 통일됐는가
- S2. `style.md` 번역투 표의 왼쪽 표현이 없는가
- S3. 근거 없는 수식어와 문서 자체를 설명하는 문장이 없는가
- S4. 날짜를 알 수 있는데 상대 시점(`어제`, `최근`)으로 쓴 곳이 없는가
- S5. 같은 개념의 표기가 하나로 통일됐는가

## 사실 (F)

- F1. '완료', '확인함'이라고 쓴 항목마다 확인 방법이 있는가
- F2. 확인하지 않은 것은 확인하지 않았다고 명시했는가
- F3. 입력에 없는 사실(담당자, 일정, 수치, 코드 내부 동작, 원인·인과)을 `추정:` 표시 없이 쓰지 않았는가

## 채널 (C)

- C1. 대상 채널에서 렌더링되지 않는 문법을 쓰지 않았는가
- C2. 템플릿 안내 주석(`<!-- -->`)을 모두 지웠는가
- C3. 템플릿 원본 각 섹션 주석의 '넣지 말 것'에 해당하는 내용이 그 섹션에 없는가

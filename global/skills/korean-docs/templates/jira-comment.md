# Jira 코멘트

**언제 쓰나**: Jira 이슈에 진행 상황이나 완료를 알릴 때. 약 15줄 안에 끝낸다.

## 골격: 진행

```markdown
**현재 상태**: <!-- 한 줄 -->

**다음 단계**
- <!-- 담당, 예정일이 있으면 함께 -->

**막힌 점**
- <!-- 누구의 무엇이 필요한지. 없으면 섹션 삭제 -->
```

## 골격: 완료

```markdown
**변경 결과**: <!-- 사용자에게 무엇이 달라졌는지 한두 줄. 넣지 말 것: 클래스명, 파일 경로 -->

**확인 방법** (<!-- 환경 -->)
1. <!-- 화면 기준 절차 -->
2. <!-- 기대 결과 -->

**남은 일**
- <!-- 배포 일정, 후속 이슈. 없으면 섹션 삭제 -->

MR: <!-- 링크 -->
```

## 예시 (완료)

```markdown
**변경 결과**: 오래 접속하지 않은 사용자가 앱을 열면 오류 화면 대신 로그인 화면으로 이동합니다.

**확인 방법** (스테이징)
1. 로그인 후 24시간 이상 지난 계정으로 앱 실행
2. 로그인 화면으로 이동하면 정상

**남은 일**
- 운영 반영: 다음 정기 배포

MR: https://gitlab.example.com/mobidoc/api/-/merge_requests/482
```

## 빈 섹션

- `막힌 점`, `남은 일`: 없으면 지운다
- Jira는 Mermaid, `<details>`, 체크박스를 렌더링하지 않는다
